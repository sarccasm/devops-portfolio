# DevOps Portfolio

Hi! I'm **Artem Fivko**.

This repository is my DevOps course portfolio. It contains all laboratory work and the final project in one place, with a workflow based on Git, pull requests, protected `main`, and a GitHub Project board.

## Professional goal

My goal is to become comfortable with the full software delivery lifecycle: version control, reproducible development environments, containerization, CI/CD, infrastructure as code, cloud deployment, and observability. I want to be able to take an application from source code to a reliable automated deployment and understand the infrastructure around it.

## Learning plan for the year

1. Build a solid Linux, networking, and Git foundation.
2. Learn container workflows with Docker and Docker Compose.
3. Build CI/CD pipelines with GitHub Actions.
4. Learn Infrastructure as Code with Terraform and configuration management with Ansible.
5. Deploy and operate services in cloud environments.
6. Study Kubernetes fundamentals and common deployment patterns.
7. Add monitoring, logging, alerts, and basic security practices to projects.
8. Complete a final DevOps project that combines the tools above.
